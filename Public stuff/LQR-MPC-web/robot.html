Run it on the robot

Connect a LEGO Education Double Motor and Color Sensor over Bluetooth, calibrate the sensor to your tape and floor, then run bang-bang, PD, LQR or MPC on a real line and compare the runs. It uses the same LineFollower logic as the hardware version of the course.

This browser has no Web Bluetooth. Use Chrome or Edge on a laptop or desktop.

The window is how far the sensor can slide across the tape edge before it reads solid black or white. It is half the width of that transition.

3 · Run

Connect both devices to run. Put the robot on the line first. It will drive as soon as you press run.

Result

Each controller keeps its latest run on the plot, so you can compare them. Blind is the share of the run the sensor was pinned fully on black or white.
