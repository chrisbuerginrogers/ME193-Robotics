Simulator: LQR vs MPC on the same track

Both controllers steer with the same LQR law. The difference is speed: LQR drives at one fixed speed, while MPC looks ahead at the curve and picks a speed it can steer. The green band is the sensor's window: outside it the robot only knows which side of the line it is on.
